# Production IT: рабочие заметки

Состояние на 05.11.2026. То, чего не видно из кода и истории коммитов.

## Где лежит код
| Каталог | Что это |
|---|---|
| `~/prodit-app` | этот публичный репозиторий; ключей подписи и секретов здесь нет |
| `~/infra/hn-archive-app` | рабочее дерево без git: ключи подписи, `google-services.json`, отсюда собирается AAB и выкатывается сервер приложения |
| `~/infra/spacecode-site` | сайт без git: `build.py`, `extra/`, `meet/`; отсюда выкатываются сайт и календарь |

Деревья могут расходиться: версия 1.4 какое-то время была только в `~/infra`. Перед правкой встреч, PHP или веб-клиента их нужно сравнить.

Соответствие файлов репозитория и сайта:
- `meet/meet_api.py` → `spacecode-site/meet/meet_api.py`
- `meet/web/index.html` → `spacecode-site/extra/meet/index.html`
- `web/production-it/` → `spacecode-site/extra/production-it/`

## Сборка и выкладка
Порядок выкладки важен: сначала сервер приложения, потом календарь. Иначе в приложении будет пустой список встреч.
```bash
cd ~/infra/hn-archive-app && prodit/deploy_prodit.sh     # сервер приложения
cd ~/infra/spacecode-site/meet && ./deploy_meet.sh       # сайт и календарь (весь dist/ через rsync --delete)
cd ~/infra/hn-archive-app && prodit/build_prodit.sh      # AAB и APK в dist/prodit/
```
Новые колонки базы встреч добавляются сами при запуске сервиса.

## Сервер
- Главные админы — `PRODIT_SUPERADMINS` в `/opt/prodit/.env`. Источник — локальный `~/infra/hn-archive-app/prodit/.superadmins` (не в git). Без него и без значения на сервере `deploy_prodit.sh` останавливается.
- `build.py` не копирует на сайт файлы `*.bak*` из `extra/`. Резервные копии можно держать рядом с исходниками.
- Резервная копия файлов 1.4: `~/infra/backup-before-1.5-20261105.tgz`.

## Открытые вопросы
- **Адреса гостей в странице `/meet`.** `DEFAULT_GUESTS` в `meet/web/index.html` — личные почты, которые видны в коде публичной страницы и в репозитории.
- **История репозитория.** Адреса из `DEFAULT_GUESTS` и контакт в `prodit/store/privacy.html` остаются в прошлых коммитах. Удалить их можно только переписыванием истории или пересозданием репозитория.
- **Android-календарь 1.5** не запускался на устройстве. Что проверить — в [RELEASE_1.5.md](RELEASE_1.5.md).
- **Старые версии приложения.** Вкладка «Календарь» показывает пустую страницу с подсказкой, пока пользователи не обновятся.
