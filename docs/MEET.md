# Production IT Meet — календарь встреч (spacecode.business/meet)

Страница `meet/web/index.html` + сервис `meet/meet_api.py` (только стандартная библиотека Python, SQLite).
Комнаты встреч — `productionit-…` на efir.umno.cloud (LiveKit Meet, оформлены в стиле Production IT).

## Что умеет
- Неделя / день (на телефоне — вкладки дней), «Сегодня», переход по неделям; языки RU / EN / SR.
- **Тёмная тема по умолчанию**, кнопка ☀/☾ в шапке (выбор запоминается в браузере, `localStorage pit.theme`).
- Клик по свободному времени — новая встреча: тема, время, длительность, гости (email), комментарий, запасная ссылка.
- Гостям уходит письмо: карточка с датой, кнопка «Присоединиться», «Как присоединиться», вложение `.ics`
  (METHOD:REQUEST). Правка — то же событие (UID, SEQUENCE+1), убранным гостям и при отмене — METHOD:CANCEL.
- **Регулярные встречи**: каждый день, по будням, каждую неделю, раз в две недели, каждый месяц, необязательно «до даты».
  В базе серия — одна строка (`recur`, `recur_until`, `exdates`), `list` разворачивает её в даты по местному времени часового
  пояса серии (перевод часов не сдвигает встречу). Гостям — одно письмо с `RRULE`, напоминания приходят к каждой дате.
  Изменить можно **всю серию** (перенос даты сдвигает все даты на столько же; смена правила — серия заново с выбранной даты)
  или **только эту дату**: отмена — `METHOD:CANCEL` с `RECURRENCE-ID`; правка — дата исключается из серии, вместо неё отдельная
  встреча в той же комнате (гости получат два письма: отмена даты и новое приглашение).
- Без кода доступа — 5 действий в сутки на браузер и IP; с кодом (`MEET_KEY`) — без лимита. Всего ≤ 50 встреч в сутки, ≤ 30 гостей.

## API (`/meet/api/`, nginx → 127.0.0.1:8823)
| Запрос | Что делает |
|---|---|
| `GET list` (`X-Meet-Key`, `X-Meet-Viewer`) | встречи от −31 до +186 дней; у серии каждая дата — отдельный элемент с общим `uid`, `recur`, `until` |
| `POST create {key, client, title, start, tz, duration, organizer, organizer_email, emails[], note, backup_link, lang, recur, until}` | создать и разослать |
| `POST edit {…, uid, occurrence, scope}` / `{uid, cancel: true, occurrence, scope}` | изменить / отменить с рассылкой; `occurrence` — `start` выбранной даты, `scope` — `one` или `all` |
| `GET health` | проверка |

`recur`: `daily`, `weekdays`, `weekly`, `biweekly`, `monthly` или пусто; `until`: `YYYY-MM-DD` или пусто. Новые колонки база добавляет сама при запуске.

Приложение Production IT ходит сюда через свой сервер (`prodit_meetings`, `prodit_meet_create`, `prodit_meet_edit`), подставляя ключ и почту организатора.
Календарь в приложении и веб-версии — свой экран на этих данных, страница сайта им не нужна. Без пропуска или кода страница `/meet`
встреч не показывает и ведёт в веб-версию `/production-it/app/#/meet/cal` (вход по коду из письма); туда же — кнопка календаря в письмах.

## Выкладка
```bash
meet/deploy_meet.sh   # страница (через сборку сайта), systemd-сервис spacecode-meet, location /meet/api/ в nginx
```
Настройки сервиса — `/etc/spacecode-meet.env`: `MEET_KEY`, `SMTP_*` / `SMTP2_*` (берутся из локального `~/send_mail_umno.py`),
необязательно — уведомления о посетителях в личку Умного плеера: `VISIT_TO`, `VISIT_TO_NAME`, `MAGICBTN_API_KEY`
(локальный файл `meet/.visit.env`, не в git).

## Шрифты
Страница использует Gilroy и Tactic Sans Extended (фирменные шрифты prod-it.com, коммерческие) — в репозиторий они
**не входят**. Положите файлы в `meet/web/fonts/` (`Gilroy-Regular.woff2`, `Gilroy-Medium.woff2`,
`TacticSansExtended-Bold.woff2`); без них страница работает на системном шрифте.
