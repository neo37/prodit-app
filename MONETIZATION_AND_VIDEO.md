# Умный плеер: монетизация и генерация видео на сервере (HyperFrames + OpenMontage)

17.10.2026 · SPACECODE DOO / bp R&D lab

## Исходные факты

- Приложение бесплатное, без рекламы и аналитики. Это обещано в Privacy Policy и в анкете Data safety: любой рекламный SDK = правка политики и анкеты.
- В версии из Google Play цифровые товары (подписки, кредиты, премиум-функции) можно продавать **только через Google Play Billing**: комиссия 15 % на первый $1 млн в год. Платёжный профиль SPACECODE DOO в Play уже есть. В APK с сайта можно принимать другую оплату, но основной канал теперь Play.
- Сервер рендера 144.91.83.27:
  - 8 vCPU EPYC, 23 ГБ RAM, 320 ГБ свободно, **GPU нет**;
  - есть node 22, ffmpeg 6.1, Python 3.12, Docker.
- Сейчас половину CPU съедает майнер в контейнере `kafkaui`, ещё ~2 ядра занимает `kronos-bot`. Пока майнер не убран, считать мощность нельзя.
- Замеры рендера HyperFrames (на 8 ядрах): **≈ 2–3 мин на 1 мин видео 1080×1920**. Шорт 1:19 рендерился 2:44, ролик 9:05 — 27:46. Один воркер — отдельный Chrome ~256 МБ.
- Стоимость озвучки ElevenLabs по оценке в коде OpenMontage ≈ **$0,25 за минуту** речи. Для коммерческого использования нужен платный тариф. Piper — локально и бесплатно, но звучит хуже.
- OpenMontage — **AGPLv3**: если наружу работает изменённый код, пользователям надо дать его исходники. Варианты: свои шаблоны и скрипты держать отдельно и вызывать только CLI/ffmpeg; либо выложить изменения открыто.

## Генерация видео на сервере — способы

Все варианты укладываются в одну схему: **заявка из приложения → очередь → воркер на 144.91.83.27 → mp4 в «Мой источник» пользователя**. Схема переиспользует существующие `space_create` / `upload` / `stream`.

### A. «Слайдшоу из моих фото и видео» — без платных API (первым делом)

- Пользователь выбирает 5–30 фото или клипов и стиль (динамичный / спокойный / «история»), формат 9:16 или 16:9, музыку из библиотеки.
- Воркер:
  - ffmpeg нормализует исходники;
  - HyperFrames-шаблон (переходы, Ken Burns, подписи, титры, водяной знак для бесплатных);
  - музыка — локальная библиотека треков с лицензией CC0 или Pixabay;
  - `npx hyperframes render` (версия закреплена).
- Себестоимость — только CPU: ролик 30 с ≈ 1–1,5 мин рендера.

### B. «Ролик из текста» (объяснялка или шорт с голосом)

- Пользователь пишет тему или текст.
- Дальше по шагам:
  - LLM (Claude API) раскладывает текст в сегменты, как `segments.py` в `projects/top-oss-month-1015-bp`;
  - озвучка: Piper бесплатно, ElevenLabs — Pro/кредиты, голоса en/sr/ru;
  - картинки: свои фото пользователя или Pexels API (бесплатно);
  - сборка тем же `build.py` с субтитрами по 5 слов → рендер.
- Себестоимость ≈ $0,25–0,3 за минуту с ElevenLabs.

### C. Субтитры и перевод готового видео (localization-dub из OpenMontage)

- Речь из видео распознаётся (faster-whisper small на CPU, примерно реальное время), получаются субтитры en/sr/ru.
- Дальше субтитры вшиваются в видео, по желанию — дубляж голосом ElevenLabs.
- Pro-функция; хорошо продаётся авторам в Черногории и Сербии (трёхъязычная аудитория).

### D. «Нарезка шортов» из длинного видео (clip-factory)

Распознавание речи → LLM выбирает 3–5 лучших моментов → вертикальная обрезка, субтитры, титр → 3–5 шортов. Тяжело по CPU, только в очереди, только Pro/кредиты.

### E. Автоконтент для роста (внутреннее использование)

- Еженедельный ролик «Топ недели в Умном плеере» из самых залайканных публичных видео (с согласия авторов). Плюс промо-шорты приложения в стиле «Топ-5 опенсорс месяца».
- Публикация в YouTube Shorts, TikTok, Reels со ссылкой на Google Play.

### Чего не делать на этом сервере

- Генеративное видео (Kling, Veo, Runway, WAN, LTX) и липсинк-аватары. Без GPU локально невозможно, через API дорого: долларовая себестоимость за секунды видео. Если нужно — только как дорогой пункт за кредиты, через внешний API.

## Техническая схема

```
Приложение ──POST action=video_job {тип, файлы из «Моего источника», текст, стиль}──► magicbtn.online/video_api.php
                                    (проверка Pro/кредитов, таблица jobs в social.sqlite)
Воркер (Docker на 144.91.83.27: node 22 + ffmpeg + python + Chrome, hyperframes закреплён)
   ├─ GET  action=job_next      (токен воркера) → задание
   ├─ скачивает исходники (stream), рендерит
   └─ POST action=job_done      → mp4 в uploads/<space>, статус «готово»
Приложение: «🎬 Сделать ролик» в «Моём источнике», статус задания, уведомление при открытии
```

- Очередь в той же SQLite, воркер сам забирает задания, входящих портов не нужно.
- Один воркер с ограничением `--cpus=6`. После удаления майнера это ≈ 20–25 минут готового видео в час, ≈ 500 минут в сутки.
- Лимиты:
  - бесплатно — 1 ролик до 30 с в день с водяным знаком;
  - Pro — 20 мин в месяц;
  - кредиты — сверх этого.
- Покупки: Play Billing Library в приложении → серверная проверка покупки через Google Play Developer API (service account) → в `social.sqlite` баланс по X-UID. Кредиты привязаны к устройству; для переноса между устройствами позже понадобится вход через Google.
